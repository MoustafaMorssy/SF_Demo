# SF_Demo

### Overview :-

This Just a way how to use dbt with snowflake DB and create some simple ETL processes
-  Option 1
    -  using visual studio code tool and use dbt-core & dbt-snowflake packages
-  Option 2
    -  use dbt studio web interface will need to make sure you can connect to snowflake DB.
 
### Steps to connect to Snowflake 
  -  please review https://docs.getdbt.com/guides/snowflake?step=1&version=1.12

### What is included
-  customized scripts to build some tables & views in Snowflake
